# X 首页粉丝数显示

一个纯 JavaScript 的 Manifest V3 浏览器插件，在 X（原 Twitter）首页时间线的发帖人昵称旁显示粉丝数，例如 `1.2万粉`。

## 功能

- 支持 `x.com/home` 和 `twitter.com/home` 的“为你推荐”“正在关注”时间线。
- 兼容 X 当前和旧版用户数据结构。
- 支持无限滚动、局部刷新和虚拟列表。
- 粉丝数使用中文紧凑格式显示，并使用 X 蓝色突出显示。
- 只读取 X 页面已经加载的数据，不主动请求 X API，不访问第三方服务。
- 粉丝数只保存在当前页面内存中，不保存历史数据、不上传数据。

## 本地安装

1. 打开 Chrome 或 Edge 的扩展管理页面：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展”。
4. 选择本项目目录。
5. 打开或刷新 `https://x.com/home`。

更新代码后，在扩展管理页面点击插件卡片上的“重新加载”，再刷新 X 页面。

## 开发和测试

项目没有第三方运行时依赖。安装 Node.js 后，在项目目录运行：

```powershell
npm test
```

测试覆盖数字格式化、用户数据解析、网络响应桥接、账号链接识别和首页路径判断。

## 隐私和权限

插件使用 `storage` 权限保存启用开关，并只匹配 X/Twitter 页面。页面桥接脚本只观察 X 自己已经发出的 `fetch` 和 `XMLHttpRequest` 响应，不会发送新的请求。粉丝数据只保存在当前页面内存中。
